# Project title:  Does the "Efficient VLA" Leaderboard Change Under Embodied-Efficiency Metrics?

# Team Members: Jeffrey Hoang, Jose Quinteros 

# Abstract:  

Efficient Vision-Language-Action (VLA) research is almost universally benchmarked using model-inference metrics — parameter count, FLOPs, and decoding throughput — alongside task success rate on simulators such as LIBERO. Recent work (Li et al., 2026) shows on a small set of internal ablations that this ranking can diverge from an *embodied-efficiency* ranking based on what actually happens during robot execution: completion time, end-effector and joint-space path length, motion smoothness, and energy. This project tests whether that divergence holds across independently-developed, published efficient-VLA methods rather than one paper's own internal interventions. We assemble a fixed pool of 3–4 public efficient-VLA methods (quantization-, pruning-, and acceleration-based), run them against a shared base VLA model on LIBERO, and log full execution trajectories rather than final success/fail outcomes. From these logs we compute both metric families and test the hypothesis that the Spearman rank correlation between a method's conventional inference-efficiency ranking and its embodied-efficiency ranking is significantly less than 1, holding task success rate constant as a control. A null result (rankings remain stable) is treated as a legitimate, reportable finding. The project's contribution is not a new compression method but a reusable, embodied-efficiency-aware evaluation harness and the first cross-method rank-correlation result in this space — a framing that must be positioned explicitly against a closely related June 2026 paper (Wang et al., "The Speedup Paradox" / TISED), which already decomposes task-level effects of multiple lossy-inference techniques and is the true closest competing work.

1. Literature Summary (7 sources, last ~1–3 years, most within the last year)
Li, Yang, Chen, Chen, Lin, and Li, "From Inference Efficiency to Embodied Efficiency" (arXiv 2603.19131, Mar 2026) — Your seed paper. <cite index="7-1">It argues that conventional VLA efficiency metrics — parameters, FLOPs, decoding throughput — apply only to the model-inference stage, while actual deployment cost is set by robotic-actuation-stage behavior such as end-effector path length, joint-space path length, smoothness, and task completion time.</cite> <cite index="2-2">Its controlled studies find that methods which look cheaper by conventional metrics often increase end-to-end execution cost or degrade motion quality even while success rate is preserved.</cite> No confirmed public code repository was found for this paper as of this search.
Wang, Chen, Li, Dong, Yang, Liu, and Jia, "The Speedup Paradox: Rethinking Inference Speed-Quality Trade-off in Embodied Tasks" (arXiv 2606.28529, Jun 2026, Tsinghua) — This is a closer competitor than the paper you listed as closest-related work, and materially changes the novelty picture (see Section 4). <cite index="11-1">It proposes TISED (Task-level Inference Speedup Effect Decomposition), an analytical framework that unifies diverse lossy inference-optimization techniques and decomposes their effects on static and dynamic embodied tasks.</cite> <cite index="11-1">It reports that on static tasks, optimization can lengthen end-to-end completion time even as per-step latency drops; on dynamic tasks, moderate lossy optimization can raise success rate above baseline; and the sweet-spot location shifts with hardware configuration.</cite> This paper already does cross-technique, task-level re-evaluation of speed-oriented compression methods — the same basic move your topic proposes.
Yu, Wang, Zeng, Zhang, Zhang, Wang, Gao, Song, Sebe, and Shen, "A Survey on Efficient Vision-Language-Action Models" (arXiv 2510.24795, Oct 2025, rev. Feb 2026) — <cite index="17-1">Presented as the first comprehensive review of efficient VLA models across the full model-training-data pipeline, it introduces a taxonomy of three pillars: efficient model design (efficient architectures and compression), efficient training, and efficient data collection.</cite> This survey and its companion GitHub repository are your best source for building a defensible "method zoo" sample rather than an ad hoc one.
Xu, Yang, Fan, Liu, Li, Li, and Zhang, "QVLA: Not All Channels Are Equal in Vision-Language-Action Model's Quantization" (arXiv 2602.03782, Feb 2026, ICLR 2026) — <cite index="26-1">Introduces QVLA, described as the first action-centric quantization framework for embodied control, using a channel-wise bit-allocation strategy instead of the uniform-bit quantization inherited from LLM quantization methods, on the grounds that minor action deviations compound into task failure in ways passive data-fidelity metrics miss.</cite> Code is public (GitHub, AutoLab-SAI-SJTU/QVLA), which makes it a strong reproduction anchor.
Fang, Liu, Du, Du, and Yang, "SQAP-VLA: A Synergistic Quantization-Aware Pruning Framework for High-Performance Vision-Language-Action Models" (arXiv 2509.09090, Sep 2025) — <cite index="37-1">Introduces SQAP-VLA, described as the first structured, training-free VLA inference-acceleration framework that jointly applies quantization and token pruning, co-designed to overcome an observed incompatibility between the two when applied independently.</cite> <cite index="42-1">Code is publicly released (github.com/ecdine/SQAP-VLA).</cite> Good second reproduction anchor — combines two compression axes in one method, useful for testing whether "stacked" compression fails embodied-efficiency checks worse than single-axis compression.
Yang, Wang, Wen, Zhongwei, Zou, Zhang, Wen, and Zhang, "EfficientVLA: Training-Free Acceleration and Compression for Vision-Language-Action Models" (arXiv 2506.10100, 2025, NeurIPS) — A training-free acceleration/compression method repeatedly cited as a baseline across the compression literature above (QuantVLA, ActQuant, Drop-Then-Recovery all cite it). Useful as a third, independent method for the re-ranking pool, and as a widely-used baseline so your rank-correlation result is legible to reviewers who know the space.
LIBERO (Liu et al.) and SimplerEnv (Li et al.) benchmark suites — <cite index="47-1">LIBERO is the standard simulation suite for VLA generalization, organized into Spatial, Object, Goal, and Long-horizon task suites, each with a fixed set of tasks and per-task demonstration episodes, and is used as the primary evaluation harness across nearly all of the compression papers above.</cite> <cite index="47-1">SimplerEnv is used as a complementary real-to-sim benchmark to check robustness of the simulation-only findings.</cite> Neither benchmark natively reports embodied-efficiency metrics (path length, smoothness, joint rotation) — these must be computed from trajectory logs, which is exactly what 2603.19131 added and what your project would need to replicate.
